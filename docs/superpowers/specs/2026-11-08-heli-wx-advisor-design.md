# 소방헬기 운항기상 임무판단 조언 시스템 — 설계서

- 작성일: 2026-11-08
- 용도: 2026년 바이브 코딩 기반 재난안전 분야 업무시스템 경진대회 출품 (제출 마감 2026-11-10 18:00)
- 사용자: 상황실 **운항관제 담당자** (조종사 아님)
- 시스템명(가칭): 헬기 운항기상 판단 도우미 (heli-wx)

## 1. 목적

출동 요청 시 운항관제 담당자가 출발 기지 → 목적지(현장)를 입력하면,
경로·출발지·목적지의 기상과 항공고시보(NOTAM)를 자동으로 모아
**「119항공대 운영 규정」 제21조(비행제한)** 기준에 비추어 임무판단 **조언**과 근거를 제시한다.
최종 판단은 사람(통제관·기장)이 한다. 시스템은 판단하지 않고 조언·근거 정리만 한다.

근거 조문: 제21조(비행제한), 제22조(특수조건), 제24조②(운항관리 담당자의 기상자료 제공 의무),
제15조⑤(기상·NOTAM 상시 파악), 제2조 32호(운고 정의: 5/8 이상), 33호(시정 정의).

## 2. 범위

### 포함
- 출발 기지 선택(설정 파일의 기지 목록), 목적지 검색/지도 클릭(카카오맵)
- 출발 예정시각(기본 현재), 순항속도(기본값 설정), 주간/야간(자동 계산 + 수동 변경), 육상/해상(자동 제안 + 수동 변경)
- 직선 경로 거리(km/NM)·소요시간·도착 예정시각 계산
- 기상청 API허브 자료 기반 제21조 판정, 바람 정보 제공
- NOTAM 붙여넣기 → D 시리즈 해석 → 경로 관계 계산
- 종합 신호등, 근거 표, 지도 표시, 보고문 복사
- 조회 이력 로그(CSV)

### 제외 (YAGNI / 고도화로 이연)
- 로그인·DB, 비행계획서 자동 제출, **풍속 한계 판정(기종별 교범 사항이므로 정보만 제공)**
- NOTAM 자동 수집(xNotam은 공개 API 없음 → 고도화), 경유지 편집, 웹(클라우드) 배포

## 3. 실행 구조

상황실 **인터넷망 PC**에서 로컬 중계 서버로 실행한다.

- 기상청 API허브는 브라우저 직접 호출 시 CORS 차단 가능성이 높고, API 키가 노출되므로 서버가 대리 호출한다.
- 카카오맵 JS SDK는 등록 도메인 필요 → `http://localhost:8000` 등록.
- **파이썬 표준 라이브러리만** 사용(설치 불필요, 타 기관 복사 배포 용이).
- 화면(정적 파일)과 중계 서버를 분리해, 추후 서버 기능이 있는 호스팅으로 옮길 수 있게 한다.

```
heli-wx/
├─ run.py              실행 진입점 (python run.py → 브라우저 자동 열림)
├─ server/kma.py       기상청 API허브 호출·응답 파싱·5분 캐시
├─ server/check_api.py 실제 응답 형식 점검용(키 마스킹 출력)
├─ web/index.html      화면
├─ web/app.js          화면 로직, 카카오맵
├─ web/judge.js        제21조 판정 규칙 (순수 함수)
├─ web/notam.js        NOTAM 해석기 (순수 함수)
├─ web/geo.js          거리, 점-선분 최단거리, 일출·일몰
├─ config.json         기준값(조문 근거 포함), 기지 목록, 반경, 유효시간
├─ config.local.json   API 키 (배포 제외, .gitignore)
├─ logs/history.csv    조회 이력
└─ tests/              파서·판정·NOTAM 테스트
```

중계 서버 엔드포인트(브라우저 → 서버): `/api/metar`, `/api/taf`, `/api/asos`, `/api/aws`,
`/api/warn`, `/api/lightning`, `/api/sigwx`, `/api/stations`, `/api/log`. 키는 서버에서만 붙인다.

## 5. 판정 규칙

### 5.1 기준값 (제21조①, config.json에 조문 근거와 함께 저장)

| 구분 | 시정 미만 시 제한 | 운고 미만 시 제한 |
|---|---|---|
| 주간 육상 | 3,200m | 1,000ft |
| 주간 해상 | 4,800m | 1,500ft |
| 야간 육상 | 4,800m | 2,000ft |
| 야간 해상 | 4,800m | 2,000ft |

- 주간/야간: 출발~도착 예정 시간대가 일몰~일출에 일부라도 걸치면 **야간** 적용.
- 육상/해상: 사용자 선택값을 비행 전체에 적용. (목적지가 해상이면 해상으로 자동 제안)
- "미만"이 제한이다. 기준값과 같으면 충족.

### 5.2 관측소 선정·구간 판정
- 구간: 출발지 / 경로 / 목적지.
- 출발지·목적지: 가장 가까운 METAR 공항(30NM 이내), ASOS(25km 이내), AWS(최근접).
- 경로: 경로 선분으로부터 METAR 30NM, ASOS 25km 이내 관측소.
- 구간 내 복수 관측소면 **최악값**으로 판정하고 해당 관측소를 표시.
- 운고 산출:
  - METAR: BKN·OVC·VV 중 최저층.
  - ASOS: 전운량 ≥ 6/10일 때만 최저운고를 운고로 인정, 아니면 "운고 없음(구름 적음)".
- 자료 유효시간: METAR·ASOS 90분, AWS 20분, 낙뢰 30분. 초과 시 ⚪.

### 5.3 항목별 판정

| 항목 | 🔴 규정상 제한 | 🟡 주의 | 근거 |
|---|---|---|---|
| 시정·운고 실황 | 기준 미만 | 기준 이상 ~ 기준×1.5 미만 | ①1·2 |
| TAF (출발 ~ 도착+30분) | 기본 예보(FM/BECMG 포함) 기준 미만 | **TEMPO·PROB** 그룹 기준 미만 | ①3 |
| 기상특보 | 태풍·강풍·풍랑·대설·호우 (주의보 이상) | 그 밖의 특보 / 특보구역 매칭 불확실 | ①4 |
| 낙뢰 | — | 최근 30분, 경로 20km 이내 → "경로 변경 검토" | ② |
| 착빙·난기류(SIGWX) | — | 경로가 해당 구역 통과 | ④⑥ |
| NOTAM | — | 경로 통과 또는 5NM 이내 & 비행 시간대 발효 | 제15조⑤ |
| 바람 | 판정 안 함 | — | 교범 사항, 평균/순간최대/풍향/10분 추세 표시 |

- 종합 = 전 항목 최악 등급.
- 🔴 시 함께 표시: "제21조① 단서 — 긴급운항 시 즉시 통제관 보고, 기종별 교범 운용한계 내에서 조종사 의견 청취 후 통제관 판단".
- ⚪(자료없음/오래됨/해석불가)는 절대 🟢로 취급하지 않는다. 종합이 🟢이고 ⚪가 있으면 "🟢 단, 일부 자료 확인 필요".
- 특보구역 매칭: 카카오 좌표→행정구역(시군구)으로 경로 샘플점(약 10km 간격)의 시군구를 구하고 특보구역명과 대조. 산지/평지 등 분할 구역은 정확 매칭이 불가하므로 🟡 + 원문 표시.

## 6. NOTAM 해석

- 입력: xNotam 조회 결과 붙여넣기(여러 건).
- **D 시리즈(번호가 `D`로 시작, 예 `D2840/26`)만 확인 대상.** 그 외 시리즈는 "확인 대상 아님 N건"으로 접어 표시.
- 구역 좌표: **E) 항목 우선**
  - `CIRCLE RADIUS 2NM CENTERED ON 373523N1265832E` 형식(도분초) 해석.
  - E) 해석 실패 시 Q-line `3735N12659E003`(도분, 반경 NM)으로 근사하고 "Q-line 기준(근사)" 표시.
- 발효기간: B)/C) `YYMMDDhhmm` UTC → KST 표시. `PERM`, `EST` 대응. 비행 시간대(출발~도착)와 겹침 판정.
- 고도: F)/G)(없으면 Q-line 하한/상한 FL) 표시. 하한이 SFC 또는 저고도면 해당.
- 경로 관계: 경로 선분과 중심 간 최단거리 − 반경 → 통과(≤0) / 근접(≤5NM) / 무관.
- 소방헬기 관련 강조: E)에 `FIRE FIGHTING`, `EMERG`, `PRIOR PERMISSION` 등이 있으면 "소방헬기 사전허가 필요" 강조, 전화번호 패턴 자동 추출.
- Q-code 표시: 예 `QRPCA` → "비행금지구역 활성".
- 해석 실패 건은 버리지 않고 "⚪ 해석 불가, 원문 확인"으로 목록 유지.

검증 예시(테스트 고정 입력):
```
D2840/26 NOTAMN
Q)RKRR/QRPCA/IV/BO/W/000/600/3735N12659E003
A)RKRR B)2609261500 C)2612261459
E)TEMPO PROHIBITED AREA ACT AS FLW
A CIRCLE RADIUS 2NM CENTERED ON 373523N1265832E
RMK : EXC SKED CIV ACFT AND INFO ASSET FLT, EMERG ACFT(FIRE FIGHTING, LIFE
GUARD, ETC) OPERATION NEED PRIOR PERMISSION FROM CDC(02-524-0315)
F)SFC G)FL600
```
기대: 중심 37°35'23"N 126°58'32"E, 반경 2NM, 2026-09-27 00:00 ~ 2026-12-26 23:59 KST, SFC~FL600, 사전허가 강조, 연락처 02-524-0315.

## 7. 출력 화면
- 상단 종합 신호등(🟢/🟡/🔴/⚪) + 한 줄 요약
- 경로 정보: 거리 km/NM, 소요시간, 도착 예정시각, 주간/야간·육상/해상 적용 기준
- 근거 표: 구간 · 항목 · 관측값 · 기준값 · 판정 · 출처/관측소 · 관측시각
- 바람 정보 카드(출발지·목적지)
- NOTAM 목록(D 시리즈, 경로 관계순 정렬)
- 지도: 경로선, 관측소(판정 색), NOTAM 원, 최근 낙뢰 점
- [보고문 복사] 버튼: 상황실 보고용 요약 텍스트
- 하단 고정: 수동 확인 링크(xNotam, 기상청 항공기상, 특보)

## 8. 오류 대응

## 9. 보안·데이터
- API 키는 `config.local.json`(서버)에만 저장, 브라우저로 전달하지 않음. 배포본 제외.
- 개인정보 미수집. 처리 데이터는 공개 기상·항공정보뿐.
- 조회 이력에는 시각·출발·목적지·종합판정만 기록.
- AI(Claude)에는 공개 규정 및 공개 NOTAM 예시만 입력, 내부자료 미입력(보고서 명시).
